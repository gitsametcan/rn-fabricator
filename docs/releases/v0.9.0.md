# rn-fabricator v0.9.0

Release date: 2026-06-24

## Summary

This release ships the reusable template library workflow. Fabricator-created projects now have a project contract that lets templates be inspected, applied safely, and captured from compatible project folders for reuse across React Native CLI apps.

## Added

- `.fabricator/project.json` contract support for projects created with the minimal starter.
- `templates info <template>` for inspecting files, dependencies, exports, and integration hints.
- `templates list --category <category>` for filtering repository or remote catalogs.
- `templates apply <template>` for applying schema v2 templates to compatible Fabricator projects.
- Safe `barrel-export` updates for supported integration points such as `src/screens/index.ts`, `src/components/index.ts`, and `src/services/index.ts`.
- `templates capture <template> --category <folder-key> --from <project> --output <dir>` for capturing reusable templates from Fabricator project folders.
- Reusable template examples:
  - `screen/main-menu`
  - `service/api-client`
  - `util/storage`
  - `layout/app-shell`
  - `component/primary-button`
- Reusable template workflow documentation.

## Changed

- Template schema v2 now describes `category`, `tags`, `dependencies`, `exports`, `integrationHints`, `targetPath`, and `targetFolder`.
- `templates copy` remains a low-level copy command, while `templates apply` performs project compatibility validation and safe integration updates.
- Dogfooding documentation now covers create, list, info, apply, capture, overwrite, and reusable catalog example flows.

## Safety Boundaries

- Existing files are skipped unless `--overwrite` is provided.
- Existing barrel exports are not duplicated.
- Unsupported exports and registry/navigation work are reported as integration notes.
- Fabricator does not insert arbitrary imports into user-authored files.
- Capture rejects invalid attempts without publishing partial template folders.
