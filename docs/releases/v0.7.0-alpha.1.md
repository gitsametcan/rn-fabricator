# rn-fabricator v0.7.0-alpha.1

Release date: 2026-06-19

This pre-release ships the guided setup apply milestone. It adds version-aware React Native toolchain profiles, profile-backed setup recommendations, and a conservative `setup apply` flow that can preview or run safe allowlisted install commands.

## Highlights

- Local `react-native-stable` toolchain profile for deterministic React Native setup recommendations.
- `setup plan --profile` and `setup plan --react-native` options for selecting a toolchain profile or React Native version.
- Profile-backed setup guidance for Node.js, Java, Xcode, CocoaPods, Watchman, and Android SDK requirements.
- `setup apply` command that prints the plan, asks for per-step confirmation, and runs only safe allowlisted commands.
- `setup apply --dry-run` for non-mutating execution previews.
- `setup apply --yes` for running safe allowlisted commands without prompts while still skipping elevated, manual, GUI, and environment steps.
- Setup execution result model and stable renderer for succeeded, failed, skipped, manual, and dry-run results.
- Expanded dogfooding workflow and troubleshooting notes for safely testing guided setup outside the repository.

## Package

Package artifact:

```text
rn-fabricator.0.7.0-alpha.1.nupkg
```

The package is produced with:

```bash
dotnet pack src/Fabricator.Cli/Fabricator.Cli.csproj --no-build --configuration Release --output artifacts/packages
```

Install from the attached package artifact:

```bash
dotnet tool install rn-fabricator --tool-path ./.tools --add-source . --version 0.7.0-alpha.1
./.tools/rn-fabricator --version
./.tools/rn-fabricator setup plan --react-native 0.76.x
./.tools/rn-fabricator setup apply --dry-run
```

## Known Limitations

- This release candidate is not yet published to NuGet.
- `setup apply` does not run `sudo` commands, install GUI applications, edit shell profiles, accept licenses, or configure Android SDK environment variables automatically.
- The generated React Native project still depends on the local React Native CLI toolchain being correctly installed.
