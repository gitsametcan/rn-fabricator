# rn-fabricator v1.0.0-beta.4

Release date: 2026-06-28

## Summary

This beta release fixes the category naming mismatch in local template lifecycle commands. Developers can now use singular template categories such as `screen` and `component` when adding, capturing, and updating templates, while existing scripts that use plural Fabricator folder keys continue to work.

## Fixed

- `templates add`, `templates capture`, and `templates update` normalize singular categories such as `screen`, `component`, `service`, and `util`.
- Existing plural folder keys such as `screens`, `components`, `services`, and `utils` remain backward compatible.
- Generated template manifests and catalog entries now persist user-facing singular category values.
- Documentation now shows singular category usage for local template capture and add workflows.
