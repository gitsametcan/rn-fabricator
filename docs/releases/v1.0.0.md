# rn-fabricator v1.0.0

Release date: 2026-06-29

## Summary

This is the first stable rn-fabricator release. It packages the React Native CLI project creation flow, environment diagnostics, guided setup planning, Fabricator-compatible starter structure, and reusable template lifecycle commands into a stable .NET tool release.

## Highlights

- `doctor` command for React Native development environment checks.
- `setup plan` and `setup apply` flows for guided dependency setup.
- `create` command for React Native CLI project creation with Fabricator project state.
- Minimal starter with splash, main, and navigation structure.
- Reusable template catalog commands for list, info, validate, apply, status, capture, add, update, remove, and copy workflows.
- Local template lifecycle support for reusable screens, components, services, utilities, layouts, and navigation slices.
- Stable singular template categories such as `screen`, `component`, `service`, `util`, and `navigation`, with backward compatibility for plural folder keys.
