# rn-fabricator v1.0.0-beta.3

Release date: 2026-06-28

## Summary

This beta release improves the generated starter structure and expands the reusable template catalog with optional navigation, screen, and component examples. New projects now start with a Fabricator-compatible navigation folder, while extra screen and component templates remain opt-in through the template commands.

## Added

- `navigation` folder support in the Fabricator project contract.
- Dependency-free starter navigation files generated under `src/navigation`.
- Repository template example `navigation/app-navigator`.
- Optional repository template example `screen/settings-screen`.
- Optional repository template example `component/empty-state`.
- Tests covering starter navigation generation, navigation template metadata, and optional screen/component template listing and inspection.

## Changed

- The default `create` output now includes a lightweight navigation structure, but optional screen and component examples are not applied automatically.
- Template catalog, reusable workflow, and dogfooding documentation now reference the `v1.0.0-beta.3` catalog.
