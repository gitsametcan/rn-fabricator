# rn-fabricator v0.7.1

Release date: 2026-06-20

## Summary

This patch release improves the dogfooding experience for `create` and includes setup guidance fixes that landed after `v0.7.0-alpha.1`.

## Changed

- Prefer `brew install cocoapods` for macOS CocoaPods setup when Homebrew is available.
- Clarify Android SDK Manager access and macOS shell profile setup steps.

## Fixed

- `rn-fabricator create` streams stdout and stderr from the underlying React Native CLI process while it runs.
- Process output remains captured for diagnostics and failure handling.
- Failure rendering avoids duplicating output that has already been streamed live.
