# rn-fabricator v0.8.0

Release date: 2026-06-21

## Summary

This release ships the first catalog-based template workflow. `create` now produces a minimal splash starter, while optional templates can be discovered and copied from a Fabricator template catalog.

## Added

- Default `minimal-splash` starter for generated React Native projects.
- `create --template-source` for applying starter files from a local or remote Fabricator catalog.
- `templates list --source` for inspecting available templates.
- `templates copy <template> --source ... --output ...` for applying optional templates to an existing project.
- Non-destructive template copy behavior with skipped-file reporting and explicit `--overwrite`.
- Repository catalog at `templates/catalog.fabricator.json` with `minimal-splash` and `basic-auth` entries.
- Dogfooding documentation for create/list/copy validation.

## Changed

- Optional templates are no longer treated as part of the initial project creation step.
- `basic-auth` is now documented as an optional catalog template that can be copied after `create`.
