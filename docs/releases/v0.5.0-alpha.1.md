# rn-fabricator v0.5.0-alpha.1

Release date: 2026-06-17

This is the first public release candidate for rn-fabricator. It packages the current MVP foundation as a .NET tool and is intended for early validation before a stable `0.5.0` release.

## Highlights

- .NET 8 CLI packaged as `rn-fabricator`.
- `doctor` command for React Native CLI environment diagnostics.
- `create` command for React Native CLI project creation orchestration.
- Built-in `basic-auth` starter template with screens, auth flow wiring, and example configuration files.
- Release, installation, usage, troubleshooting, and contribution documentation.
- GitHub Actions CI for restore, build, test, and package verification.

## Package

Package artifact:

```text
rn-fabricator.0.5.0-alpha.1.nupkg
```

The package is produced with:

```bash
dotnet pack src/Fabricator.Cli/Fabricator.Cli.csproj --no-build --configuration Release --output artifacts/packages
```

Install from the attached package artifact:

```bash
dotnet tool install rn-fabricator --tool-path ./.tools --add-source . --version 0.5.0-alpha.1
./.tools/rn-fabricator --help
```

## Verification

Release verification commands:

```bash
dotnet restore rn-fabricator.sln
dotnet build rn-fabricator.sln --no-restore --configuration Release
dotnet test rn-fabricator.sln --no-build --configuration Release
dotnet pack src/Fabricator.Cli/Fabricator.Cli.csproj --no-build --configuration Release --output artifacts/packages
dotnet tool install rn-fabricator --tool-path /tmp/rn-fabricator-release-check --add-source artifacts/packages --version 0.5.0-alpha.1
/tmp/rn-fabricator-release-check/rn-fabricator --help
```

Expected package contents include:

- `tools/net8.0/any/rn-fabricator.dll`
- `tools/net8.0/any/Fabricator.Core.dll`
- `tools/net8.0/any/Templates/basic-auth`
- `README.md`

## Known Limitations

- This release candidate is not yet published to NuGet.
- The generated React Native project still depends on the local React Native CLI toolchain being correctly installed.
- Future releases will expand release readiness checks and template coverage.
