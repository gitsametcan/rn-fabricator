# rn-fabricator v0.6.0-alpha.1

Release date: 2026-06-17

This pre-release focuses on the first real dogfooding feedback loop. It improves the `doctor` guidance, adds clean version output, documents repo-external playground usage, and introduces the first read-only guided setup command.

## Highlights

- Platform-specific `doctor` remediation guidance for macOS, Windows, and Linux.
- Clean `--version` output that prints `0.6.0-alpha.1` without source revision metadata.
- Dogfooding workflow documentation for testing the tool outside the repository.
- Guided setup design that keeps `doctor` read-only and introduces a separate `setup` command family.
- `setup plan` command that runs environment checks and prints actionable next steps without executing installers.
- Read-only package manager detection for Homebrew, winget, and apt-get.

## Package

Package artifact:

```text
rn-fabricator.0.6.0-alpha.1.nupkg
```

The package is produced with:

```bash
dotnet pack src/Fabricator.Cli/Fabricator.Cli.csproj --no-build --configuration Release --output artifacts/packages
```

Install from the attached package artifact:

```bash
dotnet tool install rn-fabricator --tool-path ./.tools --add-source . --version 0.6.0-alpha.1
./.tools/rn-fabricator --version
./.tools/rn-fabricator setup plan
```

## Known Limitations

- This release candidate is not yet published to NuGet.
- `setup plan` prints commands and manual actions but does not install dependencies.
- The generated React Native project still depends on the local React Native CLI toolchain being correctly installed.
